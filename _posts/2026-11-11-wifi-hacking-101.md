# WiFi Hacking 101: Understanding WPA Security and Password Cracking

## Introduction

Wireless networks are convenient, but their security depends on how they are configured and protected. Weak passwords and poor wireless security practices can expose networks to unauthorized access.

As part of my Security Analyst training, I completed the **WiFi Hacking 101** room on TryHackMe. The exercise introduced me to WPA/WPA2 authentication, wireless packet capture and password-cracking techniques using the Aircrack-ng suite.

In this lab, I focused on understanding how wireless handshakes work and how a captured handshake can be used to test the strength of a Wi-Fi password.

## 1. Understanding WPA/WPA2 Security

The first part of the room covered the fundamentals of wireless security.

I learned about two common WPA2 authentication methods:

- **WPA2-PSK (Personal):** Uses a shared password that wireless clients enter when connecting to the network.
- **WPA2-EAP (Enterprise):** Uses an authentication server and individual user credentials to authenticate clients.

Another important concept was the four-way handshake.

When a client connects to a WPA/WPA2 network, the access point and client exchange messages to establish the encryption keys used for communication.

The handshake does not directly reveal the Wi-Fi password. However, when captured, it can be used to test password guesses offline.

I also learned that the network's ESSID is used as a salt when deriving the encryption key. This means password guesses must be tested against the specific network.

## 2. Preparing the Wireless Interface

For wireless packet capture, a compatible wireless network adapter is required. The adapter must support monitor mode.

I was introduced to `airmon-ng`, one of the tools included in the Aircrack-ng suite.

To enable monitor mode on the wireless interface, the command is:

```bash
sudo airmon-ng start wlan0
```

The interface will commonly appear as:

```text
wlan0mon
```

The interface name can vary depending on the adapter and system configuration.

Some background processes can interfere with monitor mode. To identify and stop interfering processes, the following command can be used:

```bash
sudo airmon-ng check kill
```

This helped me understand why preparing the wireless adapter is an important part of a wireless security assessment.

## 3. Capturing Wireless Traffic with Airodump-ng

After understanding monitor mode, I explored `airodump-ng`, which is used to capture wireless packets and identify nearby access points and connected clients.

Some important command-line options include:

| Option | Purpose |
|---|---|
| `--bssid` | Specifies the target access point |
| `-c` | Selects the wireless channel |
| `-w` | Saves captured packets to a file |

A typical capture command follows this structure:

```bash
sudo airodump-ng --bssid <BSSID> -c <CHANNEL> -w capture wlan0mon
```

This command focuses the capture on a particular access point and saves the captured packets for further analysis.

One thing I took away from this section is that identifying the correct BSSID and channel is important when monitoring a specific wireless network.

## 4. Cracking a WPA Password with Aircrack-ng

This was the practical part of the exercise where I applied what I had learned.

The objective was to use a provided wireless capture file and the RockYou wordlist to identify the Wi-Fi password.

First, I extracted the supplied capture archive. Since the file had a `.tar` extension, I initially tried using `unzip`, which returned an error.

I resolved this by using the correct extraction command:

```bash
tar -xvf Captures_1578171018678.tar
```

After extraction, I identified the capture file:

```text
NinjaJc01-01.cap
```

### Understanding the Aircrack-ng options

Before running the attack, I reviewed the available Aircrack-ng options.

The important options were:

- `-b`: Specifies the BSSID of the target access point.
- `-w`: Specifies the wordlist containing password candidates.
- `-J`: Exports the capture in HCCAPX format for use with Hashcat.

### Running the password-cracking command

I used the following command against the provided lab capture:

```bash
sudo aircrack-ng -b 02:1A:11:FF:D9:BD \
-w /usr/share/wordlists/rockyou.txt \
NinjaJc01-01.cap
```

The command used the captured handshake and tested possible passwords from the RockYou wordlist.

Aircrack-ng eventually identified a matching password.

**Result:**

```text
Password: greeneggsandham
```

This demonstrated how an attacker could use an offline dictionary attack against a captured WPA handshake when the network password is weak and included in a wordlist.

## 5. CPU vs GPU Password Cracking

The final part introduced the difference between CPU and GPU-based password cracking.

I learned that GPUs are generally faster for password-cracking workloads because they can perform many calculations in parallel.

This is particularly useful when testing large wordlists or attempting more complex password combinations.
